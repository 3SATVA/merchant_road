# Merchant Road
Pixel-art fantasy side-scrolling trading game. Buy goods in one town, haul them east or west, and sell for more the farther you carry them. Plains → Snowy Forest → Mountains → Volcano, six towns, haulers, weapons, biome monsters and hazards. Static site: `index.html` plus plain script files in `core/`, `inventory/`, `world1/`, `world2/`, `assets/` (see ARCHITECTURE.md), no build step, localStorage save, deployed on Vercel.
